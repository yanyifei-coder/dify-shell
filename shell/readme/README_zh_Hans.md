# 命令行

执行 Shell 命令并返回结果，支持安全控制。

## 功能特性

- 执行 Shell 命令并获取实时输出
- 可配置命令超时时间（默认 10 秒，最大 300 秒）
- 安全控制：黑名单/白名单机制
- 工作目录支持
- 环境变量配置
- 标准输出和错误输出捕获

## 配置

| 参数 | 描述 | 默认值 |
|------|------|--------|
| 允许的命令 | 允许执行的命令列表（逗号分隔），为空表示允许所有（黑名单除外） | - |
| 阻止的命令 | 阻止执行的命令列表（逗号分隔） | 危险命令列表 |
| 工作目录 | 命令执行的工作目录 | /tmp |
| 超时时间 | 最大执行时间（秒） | 30 |

## 使用方法

1. 从 Dify 插件市场安装 Shell 插件
2. 在应用或工作流中添加 Shell 工具
3. 配置插件参数（可选）
4. 使用工具执行命令

### 示例

**输入：**
```
command: ls
args: -la /home
```

**输出：**
```json
{
    "stdout": "total 4096 May 18 21:00 .\ndrwxr-xr-x 19 root root 4096 May 18 21:00 ..\n...",
    "stderr": "",
    "exit_code": 0,
    "command": "ls -la /home"
}
```

## 安全说明

- 默认阻止危险命令（rm、sudo、chmod、dd、mkfs 等）
- 管道链检测防止绕过安全控制
- 生产环境建议使用白名单模式以获得最大安全性
- 设置合理的超时时间防止命令挂起

## 隐私

本插件不会收集、存储或向外部服务传输任何个人数据。命令执行仅在插件运行的服务器本地进行。详见 [PRIVACY.md](./privacy.md)。
